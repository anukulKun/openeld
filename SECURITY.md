# Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in OpenELD, please report it by emailing the project maintainer or opening a [GitHub Security Advisory](https://github.com/anukulKun/OpenELD/security/advisories/new).

Please do not report security vulnerabilities through public GitHub issues.

## What to Include

- A description of the vulnerability
- Steps to reproduce
- Affected versions
- Potential impact

## Response

We will acknowledge receipt within 48 hours and provide an estimated timeline for a fix.
